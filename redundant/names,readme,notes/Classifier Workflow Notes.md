## 1. Classification Hierarchy

The classifier categorizes items into four levels, sorted by ascending priority:

- Not important < Routine < Important < URGENT
    

## 2. Priority Metrics

- **Formula:** Importance $\rightarrow$ Urgency / Importance
    
- **Rule:** Importance should be calculated based on Importance and Urgency.
    

## 3. Training Pipeline

- **Phase 1 (Manual):** At first editor(me) will classify them.
    
- **Phase 2 (Automated):** Model should learn and should be able to classify them.
